Git-style control for AI chats

ChatCommit transforms ChatGPT into versioned, searchable conversations—snapshot with commits, spin off branches for experiments, merge insights back into your main dialogue.

Never lose a ChatGPT moment: Commit your chats like code, branch to explore “what-ifs,” merge the best responses, tag key insights—and revisit any version instantly.

Save snapshots as commits, create branches to test prompts, merge top ideas back into your main session, and tag your favorite moments.

📂 File Structure

  • public/ – icons & screenshots (Chatcommit1.jpg…ChatCommit10.jpg)
  • popup.html, popup.css, popup.js – extension UI
  • app/ – Next.js pages & components
    • app/commit/[id]/page.tsx – commit details & export

  • package.json, tsconfig.json, next.config.js

🔑 Key Features

Secure Login

JWT authentication ensures your chat history stays private and secure.

Branch Management

View, create & switch branches seamlessly within the chat popup.

Commit with Context

Scrape ChatGPT messages and commit only new messages since your last commit. Exports to Word with styled Tahoma font and colored role bands.

Tagging

Label commits on the fly and filter by tag in the timeline.

Timeline View

Browse your entire commit history with filters by branch, tag, or date range.

Merge & Rollback

Merge branches or rollback to any previous commit with one click.

❓ FAQ

Q: Which browsers are supported?

A: Chrome, Edge, and other Chromium-based browsers (Firefox support coming soon).

Q: Can I export commits to other formats?

A: Currently Word (.docx) and CSV exports are supported; PDF coming soon.

Q: How do I contribute?

A: Submit PRs on GitHub. See CONTRIBUTING.md.

📁 Placement & Access

  • Place product.html in your public/ folder.
  • Access via https://<your-vercel-domain>/product.html (e.g. chat-commit.vercel.app/product.html).
  • For custom domain: https://chatcommit.yourdomain.com/product.html.

🚀 Installation & Deployment

Local Development

  • git clone https://github.com/yourusername/chatcommit.git
  • cd frontend && yarn install & yarn dev
  • uvicorn backend.main:app --reload for backend

Chrome Extension

  • Load popup.html/css/js and public/ via Chrome’s chrome://extensions.
  • Pin the extension icon.

Production on Vercel

  • Connect GitHub repo to Vercel.
  • Configure env vars: NEXT_PUBLIC_BACKEND_URL=https://chatcommit.fly.dev
  • Deploy; static assets served from public/.

Accessing the App

  • Front-end at chat-commit.vercel.app.
  • API backend at https://chatcommit.fly.dev.
